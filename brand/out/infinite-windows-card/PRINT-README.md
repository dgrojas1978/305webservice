# Infinite Windows NFC card — print package

- Final trim: 85.60 × 53.98 mm (ISO/IEC 7810 ID-1 / CR80)
- Bleed: 3 mm on every edge; supplied canvas: 91.60 × 59.98 mm
- Raster resolution: 300 DPI
- Production color: CMYK TIFF (front and back)
- Two-page vendor proof: `infinite-windows-nfc-card-front-back-bleed.pdf`
- QR fallback: 24 mm, error correction Q, four-module quiet zone
- QR destination: `https://www.305webservice.com/card/infinite-windows`
- Minimum printed type: 9 pt

The PNG files are visual proofs and RGB references. Use the CMYK TIFF files or the
two-page PDF according to the printer's intake requirements. Print one physical
sample and verify QR scanning before the full run.

The vendor must confirm its exact bleed, safe-area and NFC inlay/antenna position.
Program the NTAG with the same canonical HTTPS URL used by the QR. Test NFC and QR
on current iPhone and Android devices before locking the tag permanently.
